# REST Persistent Data API

## Reflection

For this assignment, I created a RESTful API using Python and Flask to store clinical patient information. I started by setting up my project in Visual Studio Code and installing the necessary libraries, including Flask, SQLAlchemy, and Pydantic. I then created a database model and added three additional fields: blood pressure, heart rate, and visit reason.

One thing I found interesting was how the same information could be stored in two different formats. SQLite allowed the records to be stored in a structured database, while the JSON Lines file provided another way to keep track of the submitted information. I also learned how Pydantic helps validate data before it is saved.

Throughout this assignment, I became more familiar with data persistence and how POST and GET requests work with a database. This helped me better understand the importance of maintaining accurate information across different systems. Moving forward, I would like to learn more about database management and securing sensitive patient information.
